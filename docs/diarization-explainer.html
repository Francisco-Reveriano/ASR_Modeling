01 / The pipeline

Two workers share
one audio timeline.

Every sample reaches speaker detection, including silence. VAD chooses the speech regions that will become transcript rows.

Microphone or uploaded WAVResample to mono 16,000 samples/second. Retain absolute audio offsets.
Path A · Speech detection

Silero VAD

A 512-sample frame updates speech activity. Speech starts at probability ≥ 0.5. Sustained low speech probability ends it after the configured 500 ms silence window.

Output: speech start/end samples
Path B · Speaker detection

Nemotron

Continuous audio feeds overlapping model windows. The speaker cache carries history across calls. Frame probabilities become intervals for up to eight anonymous speaker channels.

Output: start, end, speaker channel

Align and split
clear speaker changes

Match speaker intervals to each VAD segment. Cut stable sequential turns before ASR; keep substantial overlapping voices together. The ASR worker can wait for timing for up to 3 s live or 30 s on upload, then use the original segment if timing is late.

Speaker-aware audio→OpenAI ASR (default)→Original transcript→English translation

Keep the cache continuous. Do not create a new Nemotron stream for every VAD segment or remove silence before diarization. Both operations break the shared time coordinates; resetting also discards speaker history. Speaker labels are anonymous channels, not verified identities.

The published 1.04 s is nominal input context, excluding computation, model loading and queue time. The actual first waveform is 1.0425 s; later waveforms are 1.065 s because the processor includes analysis-window context. First window

((C + R) × 8 − 1) × 160 + 200 samples. Here C is the scored encoder-frame count; R is right context.

Later windows

(C + R) × 8 × 160 + 400 samples. Their start comes from audio_chunk_start(), not the end of the previous window.

End of input

Flush the remaining tail with final=True. The repository adapter removes lookahead on that final call so the remaining valid frames are scored.

Use the processor properties in code. These exact raw sizes depend on the saved feature extractor: 160-sample hop, 400-sample analysis window and 512-point FFT. A mode with less context makes more calls per second; it does not guarantee better speed or speaker accuracy on your hardware.

03 / From regions to transcript rows

A pause and a speaker
change are different events.

A new speaker can start without a 500 ms pause. Silero may keep both voices in one speech segment; Nemotron’s timing can split it into turns.

Illustrative 12-second timeline with supplied speaker intervals. This page does not run either model or process your audio.

Speaker 1Speaker 2Speaker 3

The first VAD region splits at 3.20 s; the second splits at 9.00 s. Every sample inside each original VAD region is retained exactly once.

When the app cuts

  • Find single-speaker spans at least 350 ms long.
  • Use consecutive stable spans from different speakers as anchors.
  • Place a cut between the anchors, commonly in a pause.
  • Require at least 350 ms on each side of the candidate cut.

When the app keeps a mixed row

  • At least 250 ms of overlap between anchors prevents that cut.
  • A short activity flicker does not establish a new stable turn.
  • Labels follow duration overlap with the audio row.
  • A second label needs at least 80 ms and 25% of the dominant speaker’s overlap.

Diarization is an estimate. Overlapping voices cannot be separated into clean individual recordings by cutting a mono waveform. Channels may drift or split one person into extra labels. These thresholds are app rules, not confidence scores or guarantees of identity.

04 / The complete size map

Which number controls what?

Audio windows, queue batches, speech segments and playback buffering serve different purposes. All sample counts below use the app’s 16 kHz audio timeline.

LayerCurrent settingWhat it determines
Silero frame512 samples · 32 msOne VAD update; the detector retains state between frames.
VAD silence window8,000 samples · 500 msPause needed for an endpoint; decisions are quantized to VAD frames.
VAD speech padding2,400 samples · 150 ms per sideContext around a speech region, clipped or adjusted at neighboring boundaries.
Live capture pre-roll2,912 samples · 182 msRetained history: 150 ms padding + one 32 ms VAD frame.
Upload minimum speech250 ms before paddingFilters short speech regions in the offline upload path.
Speaker-worker feed batchAt most 16,000 samples · 1 sSplits queued audio for cancellation and progress; not a model-window size.
Nemotron mel hop / output grid160 samples · 10 msFeature hop and speaker-activity timestamp resolution.
Nemotron low-latency step11,520 samples · 720 msNew scored duration per full inference; context overlaps between calls.
ASR segment limit240,000 samples · 15 sUpper bound. Silence and speaker changes usually create shorter rows.
Optional TTS startup buffer60 s after the first accepted English passagePlayback lead-in; it does not set VAD or diarization chunk sizes.

The 250 ms minimum applies to WAV segmentation via get_speech_timestamps(). Live VADIterator does not use that upload-only setting. OpenAI ASR resamples accepted segments to 24 kHz internally; boundaries and speaker timing stay on the 16 kHz timeline.

1. Ask Nemotron for the exact sizes

Read the configured properties instead of hardcoding “one-second chunks.” The printed sample counts are the source of the comparison table above.

Python · processor configuration only
from transformers import AutoProcessor

processor = AutoProcessor.from_pretrained(
    "Models/Nemotron-3-Diarization",
    local_files_only=True,
)
rate = processor.feature_extractor.sampling_rate
hop = processor.feature_extractor.hop_length

for mode in ("low_latency", "very_low_latency", "ultra_low_latency"):
    processor.set_streaming_mode(mode)
    first = processor.num_samples_first_audio_chunk
    later = processor.num_samples_per_audio_chunk
    advance = processor.num_mel_frames_per_step * hop
    next_start = processor.audio_chunk_start(
        processor.num_mel_frames_per_step
    )
    print(mode)
    print(f"  first: {first} samples / {first / rate:.4f} s")
    print(f"  later: {later} samples / {later / rate:.4f} s")
    print(f"  advance: {advance} samples / {advance / rate:.3f} s")
    print(f"  second window starts at sample {next_start}")
    print(f"  nominal context: {processor.streaming_latency_ms} ms")

2. Watch Silero report speech boundaries

A streaming detector consumes exact 512-sample frames. The repository’s load_vad() sets the threshold, silence and padding values. This example displays detector events; the production live pipeline additionally buffers audio, limits segments and flushes an open utterance on Stop.

Python · example WAV path is relative to the repository
from pathlib import Path
import numpy as np
import torch

from src.pipeline import FRAME_SIZE, SAMPLE_RATE, load_vad
from src.uploads import decode_wav

audio = decode_wav(Path("sample.wav").read_bytes())
vad = load_vad()  # threshold=0.5; silence=500 ms; padding=150 ms

for offset in range(0, len(audio), FRAME_SIZE):
    real_samples = audio[offset:offset + FRAME_SIZE]
    frame = np.pad(real_samples, (0, FRAME_SIZE - len(real_samples)))
    event = vad(torch.from_numpy(frame))
    if event:
        # Events already include padding. Clamp to real audio length.
        seconds = {
            name: min(sample, len(audio)) / SAMPLE_RATE
            for name, sample in event.items()
        }
        print(seconds)

# One model call = 512 / 16_000 = 0.032 seconds.
# These are speech-boundary events, not speaker IDs or ASR text.

3. Combine VAD segments with the speaker worker

This uses the app’s actual upload and diarization helpers. Nemotron receives the full waveform once; Silero selects ASR regions. Each output turn keeps the source timeline and can be passed to the selected ASR adapter.

Python · local Nemotron inference · no transcription API calls
from pathlib import Path

from src.diarization import DiarizationSession, prepare_speaker_turns
from src.pipeline import SAMPLE_RATE, load_vad
from src.uploads import decode_wav, speech_segments

audio = decode_wav(Path("sample.wav").read_bytes())
speakers = DiarizationSession(
    max_pending_seconds=max(600, len(audio) / SAMPLE_RATE + 1)
)
speakers.push(audio)  # Preserve silence and the full original timeline.
speakers.finish()    # Signal end of input; the worker drains and flushes.

try:
    for region in speech_segments(audio, load_vad(), with_timestamps=True):
        timing = {k: v for k, v in region.items() if k != "audio"}
        turns = prepare_speaker_turns(
            region["audio"], timing, speakers, timeout=30
        )
        for turn in turns:
            duration = len(turn["audio"]) / SAMPLE_RATE
            print(
                f"{turn['start_s']:.2f}–{turn['end_s']:.2f}s",
                turn.get("speaker_id", "Speaker unknown"),
                f"{duration:.3f}s ready for ASR",
            )
finally:
    speakers.close()

What the Nemotron adapter does inside each call

The production implementation in src/diarization.py maintains a rolling audio buffer, advances by scored frames and passes speaker_cache between model calls. The sequence below is an abbreviated excerpt, not a standalone script.

Python · core inference sequence
inputs = processor(
    window,
    sampling_rate=16_000,
    is_streaming=True,
    is_first_audio_chunk=first,
    is_last_audio_chunk=final,
    return_tensors="pt",
).to("cpu", dtype=torch.float32)
if final:
    inputs["num_lookahead_frames"] = 0

with model_lock, torch.inference_mode():
    result = model(**inputs, speaker_cache=speaker_cache)
speaker_cache = result.speaker_cache

# The next output's absolute offset advances by scored frames only.
offset_seconds = scored_frames * 160 / 16_000
scored_frames += result.logits.shape[1]
intervals = processor.extract_speaker_dict(result.logits)[0]
# Add offset_seconds to each interval's Start and End.
# The adapter clips the final intervals to the real audio duration.

# Inspect a full, non-final call; times below are absolute.
print("logits shape:", tuple(result.logits.shape))
print(f"chunk offset: {offset_seconds:.2f} s")
for item in intervals:
    channel = int(item["Speaker"])
    print(
        f"channel {channel} -> Speaker {channel + 1}:",
        f"{offset_seconds + item['Start']:.2f}–"
        f"{offset_seconds + item['End']:.2f}s",
    )
